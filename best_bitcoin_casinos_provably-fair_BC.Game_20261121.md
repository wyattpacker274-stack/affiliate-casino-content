## What Makes a Bitcoin Casino Provably Fair?

Provably fair gambling is a system that uses blockchain-style cryptography to ensure neither the casino nor the player can manipulate game outcomes. At its core, a provably fair algorithm combines three elements:

1. **Server Seed** – A random string generated by the casino, hidden from the player until after the bet.
2. **Client Seed** – A random string provided by the player (or generated by the browser) that adds player-side entropy.
3. **Nonce** – A number that increases with each bet, ensuring uniqueness.

Before a round begins, the casino publishes a hashed version of the server seed. After the round, the original server seed is revealed, allowing players to hash the combination of server seed, client seed, and nonce to verify that the result was predetermined and untampered.

The best bitcoin casinos make this verification tool accessible directly in the game interface. You do not need to be a cryptographer to use it; most platforms provide a one-click “Verify” button that opens the hash in a new window.
