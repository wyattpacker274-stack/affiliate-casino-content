## What Are Provably Fair Casinos?

**Provably fair casinos** utilize a mathematical algorithm based on server and client seeds to generate outcomes that are cryptographically secure and verifiable. Unlike traditional online casinos that rely on proprietary Random Number Generators (RNGs) which are impossible to audit, provably fair platforms offer a transparent audit trail.

### How Does Provably Fair Gaming Work?
1. **Server Seed**: A random hash generated by the server.
2. **Client Seed**: A random hash generated by the player's browser or device.
3. **Nonce**: A count of how many times the game has been played.
4. **Hash**: The final result is generated by combining these elements.

Players can use a "provably fair calculator" to verify the outcome after each round. If the results match, the game is deemed fair.
